# 版式与配色

## 画布

固定 1600×900（16:9），渲染时 `scale: 2` 出 3200×1800。
横版是因为要发群、发动态，也是直播封面的通用比例。

## 栅格（单位：1600×900 的画布像素）

| 位置 | 值 | 说明 |
| --- | --- | --- |
| 外边距 `margin` | 44 | 四周统一 |
| 右侧人像列 `aside` | 372 | 可加宽到 400~440 让人像更大 |
| 列间距 `gap` | 26 | 左区与右区之间 |
| 内容顶 `top` | 180 | 留给标题 |
| 底部 `footer` | 48 | 页脚条 |
| 卡片列数 `cols` | 4 | 7 天 → 4+3；第 8 格放「公告」正好补齐 |
| 卡片切角 `cut` | 20 | 直角切掉一角，比圆角更像 UI |
| 投影 | 6px 硬投影 | `0,0,0,28` 偏移 6px，不要高斯模糊 |

**7 天 + 1 张公告 = 8 格**，4×2 刚好排满。只有 7 天会在右下留一个洞，很难看，所以补一张公告卡。

## 字号阶梯（`theme.type`）

| 键 | 默认 | 用途 |
| --- | --- | --- |
| `title` | 82 | 主标题（中文字体） |
| `version` | 32 | 标题旁的小版本号 |
| `kicker` | 14 | 顶部小字，字距 .3em |
| `subtitle` | 18 | 副标题，字距 .22em |
| `hud` | 13 | 右上角状态文字 |
| `dow` | 22 | 星期 |
| `date` | 17 | 日期 |
| `time` | 13.5 | 时段（等宽） |
| `tag` | 11.5 | 标签芯片 |
| `body` | 17 | 正文 |
| `watermark` | 74 | 卡片右下角淡数字 |
| `big` | 46 | 福利卡大数字 |
| `footer` | 12.5 | 页脚 |

判断标准：**在 1600 宽的画布上，正文小于 16 就该放大**，发到手机上会看不清。
正文最大别超过 18，否则两行中文就顶出 268px 宽的卡片。

## 配色配方

### 白底赛博（默认，配白底人像）

```
paper #ffffff   ink #0b0e13   body #30353e   muted #6a727e
accent #0a6c86  accent2 #e80068  highlight #d68414  grid #e6eaf0
card #ffffff    hot #fff8fb
```

要点：白底上霓虹要**压暗**才有对比度（`#0a6c86` 而不是 `#00e5ff`），
标题用黑字 + 青/品红各偏 2.5px 的错位描边来表达信号偏移。

### 深色霓虹

```
paper #05070d   ink #dff6ff   body #cfe9f5   muted #5f7c8c
accent #00e5ff  accent2 #ff2d75  highlight #ffb020  grid #0a1220
```

要点：`effects.dark = true` 会开启辉光和全息扫描线；人像必须抠图，边缘羽化 20~40px。

### 粉色可爱（参考「魔王酱周历」那类）

```
paper #fff5f7  ink #5a3b46  accent #ff7fa8  accent2 #ff4f8b  highlight #ffd166
```

要点：切角改圆角（`cut: 0` 并用 border-radius）、投影换成柔光、
加粉色虚边贴纸框。这种风格人像通常带白底，直接贴。

### 黑白极简

```
paper #ffffff  ink #111111  accent #111111  accent2 #111111
```

只靠字重、字号、留白撑场面。适合不想踩配色风险的时候。

## 字体搭配

| 角色 | 推荐 | 备注 |
| --- | --- | --- |
| 中文标题 | ZCOOL QingKe HuangYou / ZCOOL KuaiLe | 有性格，但小字号糊 |
| 拉丁标题 | Orbitron 900 / Audiowide / Michroma | Orbitron 只适合大字 |
| 数字/日期 | Chakra Petch 700 / Oxanium 700 | 不会把 8 看成 B |
| 等宽/时间 | Share Tech Mono / VT323 | 自带仪表盘感 |
| 拉丁正文 | Rajdhani 600 / Chakra Petch | 瘦长紧凑 |
| 中文正文 | 系统黑体（微软雅黑 / 苹方） | 别用装饰字体 |

**一条铁律**：装饰字体只给大字号用。16px 以下的字一律换系统黑体或等宽。

## 卡片内部节奏

```
卡片 padding 13/14
├─ 星期 + 日期          y+13（22px 粗体）
├─ 时段                 y+68（等宽 13.5，强调色）
├─ 标签芯片             紧随其后，黑底白字，行高 17
├─ 正文                 y+6 起，行高 23
└─ 右下角淡数字         贴底，颜色 = 纸色与墨色 7% 混合
```

时段之间用**虚线**分隔（`1px`，跳 5 画 4），比实线轻，也不跟卡片边框打架。
