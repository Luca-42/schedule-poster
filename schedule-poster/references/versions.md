# 三版本背景配方

首轮必须一次给三版，三版要**看起来是三张不同的图**，不是同一张换个色。

三版共用同一个 `theme.json` 的 `layout` 和 `type`，**只改 `colors` 和 `effects`** ——
这样用户挑中哪版，其余两版的设计成本都不浪费。

输出命名：`播表-V1撞色.png` / `播表-V2图形.png` / `播表-V3图底.png`。

---

## V1 撞色：从人像里取三个色

```bash
python scripts/palette.py 项目/portrait.png
# {"accent": "#16cde3", "accent2": "#575d77", "highlight": "#e31662"}
```

取色脚本会剔掉背景白和死黑，只留不透明、有饱和度的颜色；
凑不满三个就用色相旋转补一个对比色，所以拿到的一定是三个能看的色。

分配规则：

| 槽位 | 用途 | 怎么选 |
| --- | --- | --- |
| `paper` | 纸底 | 取色里最亮那个，或者直接白 `#ffffff` |
| `ink` | 正文、描边 | 最深的那个，或者 `#0b0e13` |
| `accent` | 主强调（时间、标签、装饰） | 饱和度最高的那个 |
| `accent2` | 次强调（重点日、数字） | 和 accent 色相拉开最大的那个 |

```json
"colors": {
  "paper": "#ffffff", "ink": "#0b0e13",
  "accent": "#16cde3", "accent2": "#e31662", "highlight": "#575d77",
  "card": "#ffffff", "hot": "#0b0e13"
}
```

**撞色的关键是只用三个色。** 一加深灰、浅灰、第四个点缀色，立刻从「设计」掉回「随便配的」。
灰阶只能靠黑加透明度做。

让画面「跳」的手法：把 1~2 张重点日卡片**反白**（`hot` 用 ink 底 + paper 字），
其余白底黑字，accent 只出现在时间、标签、日期和线上。

### 撞完色还要撒素材，不然就是纯色块

**只换配色、不叠素材，出来一定单调** —— 满屏白卡片，颜色再多也只是"换了个皮肤的表格"。
撞色定完，必须再从第 2 步的素材里拿东西往背景上点，做到"有东西但压得住"。

往哪撒（按优先级，够用就停）：

1. **页头**：放大 2~3 倍的图案淡影，或一条斜纹块，压在标题后面。
2. **页边和四角**：半调网点竖条、刻度线、四角框线、小十字标记（间隔 40/80px，别铺满）。
3. **卡片缝**：彩色数据条、圆点列，横穿两行之间。
4. **卡片内部**：大号水印数字（用 accent 的 8%~12% 透明度），右下角一个 L 形框线。
5. **人像背后**：同心圆、放射线、一团极淡的 accent 光晕。

三条卡尺：

- **透明度 6%~15%**。装饰是背景，不是内容；超过 20% 就开始和正文抢注意力。
- **永远压在卡片下面**。撒完用 `read_image` 看一眼正文区域，任何一个字被压到都算过头。
- **颜色只能用那三个色**。撒素材时最容易手滑加第四种颜色，一加就破功。

换句话说：撞色解决"气色"，素材点缀解决"密度"，两件事都得做。
只做前者的成品会像 PPT 换主题色，只做后者会像素材堆。

## V2 夸张图形：把素材放大堆起来

素材来自第 2 步的 `项目/assets/patterns/svg/`（Kenney CC0，84 组纯黑矢量）和 `assets/icons/`。

要点：

1. **尺寸要夸张**：一个形状占画布 40%~70%，一屏只放 2~3 个，不是撒一排小图标。
2. **必须叠压**：形状之间重叠 30% 以上，有前后关系才叫「堆叠」。
3. **透明度 6%~18%**：超过 25% 会盖住文字；低于 5% 打印出来看不见。
4. **旋转 -20°~20°**：全部摆正会像装饰边框，歪一点才有张力。
5. **颜色只用主题色**：形状填充用 `accent` / `accent2`，别引入新色。

PIL 里大概长这样（渲染脚本里加进 `background()`）：

```python
def shape(path, size, color, alpha, angle):
    doc = pymupdf.open(path); page = doc[0]
    z = px(size) / page.rect.width
    pix = page.get_pixmap(matrix=pymupdf.Matrix(z, z), alpha=True)
    im = Image.open(io.BytesIO(pix.tobytes("png"))).convert("RGBA")
    solid = Image.new("RGBA", im.size, color + (255,))
    solid.putalpha(im.getchannel("A"))            # 用素材的 alpha 当蒙版染色
    im = solid.rotate(angle, expand=True, resample=Image.BICUBIC)
    im.putalpha(im.getchannel("A").point(lambda v: int(v * alpha)))
    return im
```

Kenney 的图案是**实心块挖掉一个白形**。想要「只有图形、没有方块」，
就把 alpha 反相：`a.point(lambda v: 255 - v)`，得到星形/菱形/圆环这种干净图形。

另一条路是重复条纹（斑马）：54px 一个循环，蓝黑交替压 8%~15%，
在页头、边距和卡片缝里透出来，密度够但完全不抢字。

## V3 图片底：AI 图 / 合规网图打底

**有绘图工具**：生成 16:9 主题图。提示词里明确要求「主体偏右、左侧留白」，
不然卡片压上去会把主体挡掉一半。

**没有绘图工具**（多数沙箱）：下载合规图源，优先级：

1. 官方原画 / 宣传图（裁掉水印和标题条后可用）
2. CC0 素材站（Kenney / OpenGameArt）
3. 站内已有素材自己做程序化生成

裁水印的做法：`read_image` 看图，找出水印和标题条的位置，
用 `Image.crop()` 只保留中间干净区域，再拉伸到 16:9。宁可裁小再放大，也别把水印留在画面里。

参数：

```json
"effects": { "image": "assets/bg/hero.jpg", "scrim": 90 }
```

- `scrim` 60~120：白蒙版的不透明度，越高照片越淡、字越清楚。
- 卡片 `card` 改成半透明（0.80~0.88，需要 `alpha_composite`，见坑 #2），
  照片从卡片底下透出来，才有「毛玻璃」的层次。
- 人像**必须抠图**，白底图放照片上会留一块白。

## 三版都做完之后

1. 把三张 PNG 并排放一起，自己先看一眼：**缩小到 25% 时还分得清是三版吗？** 分不清就重做。
2. 让用户挑一版，再用这一版的配色去同步 `editor_template.html` 的 `:root` 和装饰层。
3. 编辑器只做一个版本 —— 三版各配一个编辑器是浪费。
