# 参考模板

两个完成度样本。做新项目时先看它们，别凭想象对齐。

## 基准-白底赛博.png

白纸底、细黑描边切角卡片、右侧人像列、页头页脚齐活。
**第 3 步「搭框架」的验收标准就是这张**：结构、字号层级、卡片节奏到位，但不上重装饰。

## 蓝黑粗框-海报.png + 蓝黑粗框-模板/

同一套框架的第二版：卡片缩小、边框加粗到 2.2~2.6px、投影更重、配色收成蓝黑两色。

- `蓝黑粗框-模板/赛博朋克播表.html` —— 可直接改的 HTML 源模板（1600×900，含 @font-face 与装饰层），
  用 `scripts/build_editor.py --template` 走一遍就能变成单文件编辑器。
- `蓝黑粗框-模板/img/` —— 该模板引用的人像（透明底 / 白底各一份）。

注意：这里放的是**源模板**，不是构建产物。单文件编辑器（8MB，字体图片全内嵌）
由 `build_editor.py` 现场生成，不要把这个目录当成品发人。
